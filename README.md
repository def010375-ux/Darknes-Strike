# Darknes Strike

Мобильный тактический FPS на Godot 4 для Android.

## Текущий этап: 0.1.0 — FPS foundation

- Процедурная тренировочная арена с коллизиями.
- Камера от первого лица.
- Передвижение WASD / виртуальный левый стик.
- Обзор мышью / свайпом правой стороны экрана.
- Прыжок и тестовый hitscan-выстрел.
- Мобильный HUD.
- Рендерер Compatibility для широкой поддержки Android GPU.

## Управление

- ПК: WASD, мышь, Shift, кнопки HUD.
- Android: левая половина экрана — движение; свайп справа — обзор; кнопки JUMP и FIRE.

## Сборка

Открой проект в Godot 4.4.1 или новее. Для Android установи Android export templates и настрой Android SDK/JDK в Editor Settings. CI workflow находится в папке .github/workflows.

Проект — самостоятельная игра, вдохновлённая жанром тактических FPS. Не содержит оригинальных игровых ресурсов Valve.
