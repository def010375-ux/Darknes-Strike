# Darknes Strike

**DSm — мобильный тактический FPS на Godot 4.4.1.**

Проект развивается на базе существующего прототипа: исходный проект и Android CI сохранены, игровая архитектура постепенно перерабатывается.

## Текущая переработка

- Главное меню в фирменной чёрно-золотой палитре.
- Экран настроек качества: экономичный, сбалансированный и высокий режимы.
- Расширенная тренировочная арена с укрытиями и физическими коллизиями.
- Базовый матч против шести ботов с преследованием, атакой и получением урона.
- Здоровье, магазин на 30 патронов, запас боеприпасов и перезарядка.
- Мобильное управление: движение слева, обзор свайпом справа, кнопки прыжка, бега, стрельбы и перезарядки.
- Иконка DSm в чёрно-золотом стиле.
- Рендерер Compatibility и настройки качества для Android-устройств.

## Управление

- Android: левая часть экрана — движение; правая — обзор; экранные кнопки — действия.
- ПК: WASD, мышь, Shift; Escape освобождает курсор.

## Производительность и размер игры

Проект ориентирован на Android и использует настраиваемое 3D-масштабирование. Размер APK будет расти за счёт реального игрового контента: карт, моделей, текстур, звуков, анимаций и режимов. Пустые данные не добавляются ради искусственного увеличения размера. Цель по объёму полного набора контента — около 1 ГБ, с проверкой памяти, FPS и времени загрузки на мобильных устройствах.

## Сборка

Android APK собирается GitHub Actions workflow из `.github/workflows/android-build.yml`.
